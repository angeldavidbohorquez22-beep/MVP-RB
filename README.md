
# 🌱 EcoComunidad | Gestión de Residuos y Participación Ciudadana

EcoComunidad es un prototipo de aplicación web diseñado para promover la participación ciudadana en la identificación y gestión de residuos sólidos dentro de las comunidades.

La plataforma permite reportar puntos de acumulación de basura, consultar zonas contaminadas, realizar seguimiento a las solicitudes y visualizar información relacionada con la recolección de residuos.

## 🎯 Objetivo del proyecto

Desarrollar una solución digital que facilite la identificación de problemas ambientales relacionados con los residuos sólidos, promoviendo la participación ciudadana y contribuyendo a la construcción de comunidades más limpias y sostenibles.

## 🌎 Objetivo de Desarrollo Sostenible

El proyecto está alineado con el **ODS 11: Ciudades y Comunidades Sostenibles**, que busca lograr que las ciudades y los asentamientos humanos sean inclusivos, seguros, resilientes y sostenibles.

EcoComunidad contribuye a este objetivo mediante herramientas digitales orientadas a mejorar la gestión de residuos y fomentar la conciencia ambiental.

## ⚙️ Funcionalidades principales

- **Reporte de residuos:** registro de puntos contaminados mediante ubicación, descripción y fotografía.
- **Mapa de puntos contaminados:** visualización de reportes mediante marcadores interactivos.
- **Seguimiento de solicitudes:** consulta del estado de los reportes mediante códigos de identificación.
- **Registro de recolección:** ingreso de cantidades de residuos recolectados.
- **Historial de recolección:** consulta de registros y clasificación por tipo de material.
- **Estadísticas:** visualización de información relacionada con la recolección de residuos.
- **Educación ambiental:** recomendaciones sobre reciclaje, separación de residuos y buenas prácticas ambientales.
- **Diseño responsivo:** interfaz adaptable a computadores y dispositivos móviles.

## 🚀 Ejecución del proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo `index.html` en un navegador web.

No requiere instalación de dependencias ni configuración de un servidor.

## 📌 Alcance del proyecto

EcoComunidad se presenta como un **Producto Mínimo Viable (MVP)** desarrollado con fines académicos.

El sistema utiliza información de demostración y funcionalidades implementadas directamente en el navegador, sin conexión a una base de datos externa.

El mapa es una representación visual del prototipo y no utiliza servicios cartográficos en tiempo real.
